📜 How to Get Your Collection JSON File

  1. Log In: Go to app.narutoninjacards.com and sign in.
  2. Open Developer Tools: Press F12 (or Ctrl + Shift + I).
  3. Open Network Tab: Click the Network tab in DevTools.
  4. Locate Response: Click Collection on the site, find the me request, right-click → Copy response.
  5. Save File: Paste text into Notepad and save as naruto_collection.json.
  6. Console Shortcut:

    Or paste this into the DevTools Console tab and press Enter:

    fetch('/api/user/me').then(r=>r.json()).then(d=>{const a=document.createElement('a');a.href=URL.createObjectURL(new Blob([JSON.stringify(d,null,2)],{type:'application/json'}));a.download='naruto_collection.json';a.click();});
