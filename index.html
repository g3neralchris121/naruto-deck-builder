📜 How to Get Your Collection File

  1. Log into app.narutoninjacards.com.
  2. Press F12 to open Developer Tools and select the Network tab.
  3. Click Collection on the site.
  4. Find the me request in the network list, right-click it → Copy response.
  5. Paste it into Notepad and save it as collection.json.
