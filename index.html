📜 How to Get Your Collection JSON File

  1. Log In: Go to app.narutoninjacards.com and sign in.
  2. Open Developer Tools: Press F12 (or right-click anywhere and select Inspect).
  3. Open Network Tab: Click the Network tab at the top of the inspector panel.
  4. Refresh Page: Press F5 to reload the page so requests are logged.
  5. Locate Response: Type me in the Network filter box, right-click the me request → Copy → Copy response.
  6. Save JSON File: Paste the copied text into a text file and save it as naruto_collection.json.
