📜 How to Get Your Collection JSON File

  1. Log In: Go to app.narutoninjacards.com and sign in.
  2. Open Developer Tools: Press F12.
  3. Open Network Tab: Click the Network tab.
  4. Locate the Collection Response: Right-click on the me request → Copy response.
  5. Save JSON File: Save it as naruto_collection.json.
